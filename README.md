# (주)아진엑스텍 6축 로봇 모션 제어 & 속도 프로파일 교육 시뮬레이터

> **NI2.0 AID 해커톤 | 매칭 기업: (주)아진엑스텍 (AJINEXTEK)**  
> 전공 학생들이 산업용 6축 수직다관절 로봇의 모션 제어 원리(가속·등속·감속 속도 프로파일)와 관절 움직임을 직관적으로 학습할 수 있도록 구현한 3D 인터랙티브 웹 시뮬레이터입니다.

 **Live Demo:** `https://[깃허브아이디].github.io/AjinXtech-robotcontrol-simulator/` *(PC 브라우저 권장)*

## 프로젝트 배경 및 목적 ##
모션 제어 학습 초기 단계에서는 수치나 수식만으로 **가속·등속·감속 구간 변화**가 실제 로봇 관절에 어떤 움직임과 부하를 주는지 직관적으로 이해하기 어렵습니다.  
본 프로젝트는 **(주)아진엑스텍의 실제 6축 수직다관절 로봇 제원**을 3D 디지털 트윈 환경에 반영하여, 그래프의 속도 프로파일 변화와 로봇 팔의 3D 궤적을 실시간으로 동기화해 확인할 수 있는 교육용 시뮬레이터를 목표로 개발했습니다.

## 반영된 실제 로봇 제원 (Data Sheet 기반) ##
상단 모델 선택 메뉴를 통해 아진엑스텍 주력 6축 로봇 2종의 실제 가동 범위 및 축별 최대 각속도(`°/s`) 스펙을 전환하며 테스트할 수 있습니다.

| 구분 | **ARB-10-1420** (중하중·장거리형) | **ARB-3-560** (초고속·소형) |
| :--- | :---: | :---: |
| **축 구성** | 6축 수직다관절 | 6축 수직다관절 |
| **가반하중 (Payload)** | 10 kg | 3 kg |
| **최대 도달거리 (Reach)** | 1,420 mm | 560 mm |
| **축별 최대 속도 (J1~J6)** | 220 / 230 / 260 / 440 / 440 / 700 °/s | 450 / 450 / 525 / 600 / 600 / 850 °/s |
| **적용 제어기** | ARC20 | ARC20 |

## 주요 기능 ##

### 1. 3D 6축 로봇 팔 렌더링 및 실시간 좌표계
* **3D 기구학 모델링**: 작업 반경 가이드(`R1420` / `R560`) 및 끝단 이동 궤적 라인 시각화
* **실시간 TCP 베이스 좌표계**: 끝단의 위치($X, Y, Z$) 및 자세($Rx, Ry, Rz$) 수치 실시간 표시
* **직관적인 시각 피드백**:
  * **관절 하이라이트**: 수동 슬라이더 조작 또는 특정 기어 그래프 선택 시 해당 3D 관절 부품 빨간색 점멸
  * **회전 방향 화살표**: 기어 움직임에 따라 회전 방향을 가리키는 슬림 3D 리본 화살표 표시

### 2. 접이식 속도·위치 프로파일 그래프
* **전체(J1~J6) & 개별 기어 뷰**: 6개 축의 속도 프로파일을 6칸 그리드로 동시에 비교하거나, 특정 축을 클릭해 속도(`°/s`)·위치(`°`) 상세 그래프 확인
* **구간별 색상 구분 및 필터링**:
  * 🔴 **가속 구간 (Acceleration)** / 🟠 **등속 구간 (Constant)** / 🟡 **감속 구간 (Deceleration)** 색상 분리
  * 상단 필터 버튼을 통해 원하는 구간(예: 가속 구간만)을 선택적으로 강조 표시

### 3. 시연용 데모 모션 3종 & 티칭 제어
* **데모 1 (픽 앤 플레이스)**: 작업대 간 물체 이송 및 표준 가감속 궤적 관찰
* **데모 2 (정밀 용접/연마 궤적)**: 6개 축이 동시에 복합 회전하는 다축 동기화 경로 시연
* **데모 3 (고속 반복 과부하 테스트)**: 급가속·급감속 왕복 시의 가파른 프로파일 기울기 확인
* **배속 및 티칭 기능**: `0.25x` ~ `4.0x` 재생 배속 조절, 수동 관절/직교 조그 조작, 티칭 포인트 저장 및 순차 재생 지원
